# Fiche d'évaluation – Compétition Robotique

POC React mono-page pour saisir les évaluations d'une compétition de robotique et afficher un classement automatique (localStorage, pas de backend).

**App live** : https://robo-run-rankings.lovable.app

## Développement

Prérequis : Node.js et npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
